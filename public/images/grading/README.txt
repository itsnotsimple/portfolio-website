Before / After color-grading slider images
==========================================

Drop two 16:9 frames in this folder to power the Before/After slider:

  before.webp   — the RAW / ungraded frame
  after.webp    — the final COLOR-GRADED frame

Tips:
- Use the EXACT same frame (same crop & framing) for both, so only the grade differs.
- Recommended size: 1280×720 or larger, exported as WebP.
- Until these files exist, the slider automatically shows styled gradient placeholders,
  so the section already looks intentional with no broken images.
